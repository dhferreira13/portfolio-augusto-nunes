# Augusto Nunes — portfólio estático V3

Site pessoal independente, com 12 destaques e 48 entradas de acervo.

Abra `index.html` ou rode `python -m http.server 8000` nesta pasta. Não requer APIs nem instalação de pacotes.

Os dois arquivos em `arquivos/` são PDFs V3. Para atualizar matérias, edite `data/publicacoes.json` e execute `python atualizar_html.py` na mesma pasta. O gerador preserva as seções fixas, mas não atualiza automaticamente PDFs nem todas as contagens de texto fixas.

No GitHub Pages, publique o **conteúdo desta pasta na raiz** do repositório; selecione `main` + `/(root)` em Settings > Pages. Não há deploy feito nesta entrega.
